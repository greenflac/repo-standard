# Пример чистого репозитория

Фикстура-эталон: на ней прибор обязан молчать. Держится ровно тем набором файлов,
который требует базовая ступень стандарта, — ни одного лишнего.

## Как запустить

```
python3 src/app.py
```

## Как проверить, что работает

```
python3 -m repo_lint fixtures/clean
```

Команда печатает `проверено N, нарушений 0`.

## Что здесь лежит

`src/app.py` — точка входа, вся развилка вынесена в `target_url`, поэтому она
достижима тестом. `docs/` разложена по жанрам: инструкция отдельно, журнал
сессий отдельно. `.env.example` перечисляет каждую переменную, которую читает код.
