## Задача
Собрать методологию оформления репозиториев как часть харнеса: норма, процедура, прибор.

## Решения сессии (что и почему)
- Форма — док + skill + скрипт-гейт. MCP-сервер отвергнут: он даёт инструменты, а нужна
  норма плюс измеритель; skill и CLI покрывают тот же сценарий без отдельного процесса.
- Ступени две: `base` обязательна всем, `public` включается флагом для показываемых наружу.
- Полномочия чистилки: правит сама, человек смотрит дифф; удаление файлов, нужных проду,
  и правки в чужих модулях — только через вопрос.
- Язык нормы — русский; язык README репозиториев-клиентов определяется их читателем
  и чисткой не трогается.
- Дом — отдельный репозиторий `greenflac/repo-standard`; создан оператором, так как
  GitHub-интеграция сессии не имеет прав на `POST /user/repos` (403).
